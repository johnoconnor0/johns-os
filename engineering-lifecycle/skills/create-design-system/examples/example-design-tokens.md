# Design Tokens Example

## Prompt

```text
Use create-design-system to define colours, typography, spacing, buttons, inputs, cards, tables, empty states, and accessibility rules for the MVP.
```

## Expected Handling

- Inspect existing design tokens, CSS variables, Tailwind config, global styles, and component variants before proposing values.
- Separate existing conventions from proposed design decisions.
- Use implementation-ready token names.
- Avoid claiming final brand rules when no brand source exists.

## Example Token Categories

```text
color.background.default
color.background.muted
color.text.primary
color.text.secondary
color.border.default
```
