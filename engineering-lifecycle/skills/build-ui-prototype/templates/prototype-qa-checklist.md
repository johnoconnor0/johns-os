# Prototype QA Checklist

## Smoke Test

- [ ] App starts locally.
- [ ] Prototype route loads.
- [ ] Main journey can be completed.
- [ ] No obvious console errors.
- [ ] Layout works at desktop width.
- [ ] Layout works at mobile width.

## UI States

- [ ] Empty state visible.
- [ ] Loading state represented where relevant.
- [ ] Error state represented where relevant.
- [ ] Success state represented.
- [ ] Permission/unauthorised state represented if relevant.

## Accessibility

- [ ] Keyboard navigation works for primary actions.
- [ ] Form fields have labels.
- [ ] Buttons/links have clear text.
- [ ] Focus states are visible.
- [ ] Colour is not the only signal.

## Data And Behaviour

- [ ] Mock data is clearly marked.
- [ ] No fake integration is presented as real.
- [ ] Form validation behaviour is explicit.
- [ ] Error handling is visible.
