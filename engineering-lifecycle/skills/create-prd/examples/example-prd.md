# Product Requirements

## Goal

Allow customers to start and complete checkout from a saved cart.

## Requirements

- Create a checkout session for a valid cart.
- Show actionable errors when checkout cannot start.

## Acceptance Criteria

Users can reach the provider checkout page from the cart screen.
