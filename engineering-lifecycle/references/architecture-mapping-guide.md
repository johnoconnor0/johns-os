# Architecture Mapping Guide

System maps must be evidence-bound.

## Inspect

- runtime entrypoints,
- app and package boundaries,
- routes, handlers, jobs, and workers,
- schema and migration files,
- config and deployment files,
- auth and permission checks,
- existing lifecycle artifacts.

## Map

- actors and external systems,
- major workflows,
- components and ownership boundaries,
- data entities and data flow,
- security boundaries,
- deployment and operational shape,
- failure modes,
- missing information.

## Evidence

Mark inferred claims clearly. Do not fill missing architecture with guesses.
