# Support

Start with the root [README](README.md), the relevant plugin README, and the documented validation commands.

For a reproducible bug, open an issue with:

- plugin or marketplace surface;
- version and operating system;
- exact command or installation flow;
- expected and actual result;
- redacted logs.

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a public issue. Feature requests should explain the user problem and the smallest useful proposal.
